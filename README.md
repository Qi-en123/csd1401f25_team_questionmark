# Ahmad's Plants

Time-and-points game in C++ (CProcessing library): the player uses tools to
plant and water crops, defends them from pests, and wins by reaching a target score.
Team of 3.

## My role
- 5 UI screens: main menu, pause, win, lose, credits
- Admin pages
- Game map tiling

## Build and run
1. Open `Final_Proj/Final_Proj.sln` in Visual Studio. <- check the name
2. Build in Debug or Release (x64).  <- check
